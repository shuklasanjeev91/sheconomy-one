# SHEconomy launch kit

Send these yourself. The website is https://www.sheconomy.in. The iPhone app is https://apps.apple.com/app/id6499198194. The Android app is https://play.google.com/store/apps/details?id=com.sheconomy.ecommerce.

## WhatsApp note for a seller to forward

Replace the shop name and link, then ask the seller to send it to customers and groups they already talk to.

```
I sell on SHEconomy, a marketplace for women-led shops.

You can see {Shop name} here:
{https://www.sheconomy.in/shop/your-slug}

Browse other women-led shops at https://www.sheconomy.in

iPhone: https://apps.apple.com/app/id6499198194
Android: https://play.google.com/store/apps/details?id=com.sheconomy.ecommerce
```

Example for Wheat Raja:

```
I sell on SHEconomy, a marketplace for women-led shops.
```

## After the site deploy

1. Open Google Search Console and add the property `https://www.sheconomy.in`.
2. Submit `https://www.sheconomy.in/sitemap.xml`.
3. Indexing takes days. The sitemap is what gives Google the shop and product URLs.
